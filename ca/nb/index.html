    NBPNP新不伦瑞克省提名移民项目

    飞出国：新不伦瑞克省（ New Brunswick）为加拿大大西洋四省之一，该省的西部与美国的缅因州接壤，西北部则和魁北克省毗邻，这里阳光明媚，四季分明。

    新不伦瑞克省人口约75.6万人，是加拿大唯一英法双语同为官方语言的省份之一，也是除魁北克外的最大法语区。

    新不伦瑞克省提名项目 New Brunswick Provincial Nominee Program ，简称 NBPNP ，也就是我们常说的NB省省提名。

    NBPNP是NB省与加拿大省政府合作的省移民项目。作为经济类移民的一种，它从全世界选拔合适的技术工人，这些人将会居住的在NB省，并且会在NB从事全职持续的工作，为NB经济做出贡献。

    2025年4月4日起，AIP大西洋移民计划暂停，因NB省本年度配额已用完。

    NBPNP EE类别

    飞出国：NB省提名EE类别专为联邦EE快速通道池中的高技能外国国民而设计。这些人希望将NB省作为永久居住地，并为该省的发展做出贡献。来自NB省的提名将增加他们获得IRCC邀请申请永久居留权的机会。

    2025年起，NB省提名EE类别划分为以下两个子类别：NB工作类 和 NB利益类。目前，NB省移民局不考虑以下NOC代码的职业或工作offer的意向书（EOI）：

    • 会计技师及记账员 (NOC 12200)
    • 行政助理 (NOC 13110)
    • 零售与批发贸易经理 (NOC 60020)
    • 餐厅与食品服务经理 (NOC 60030)
    • 零售主管 (NOC 62010)
    • 食品服务主管 (NOC 62020)
    • 厨师 (NOC 63200)
    • 烘焙师 (NOC 63202)

    EOI有效期为365天，申请并不以先到先得的方式进行审理，NB省移民审查申请并采取定向邀请的方式。

    申请条件 - 飞出国

    NB工作类

    • 在联邦EE池中拥有有效的个人账户；
    • 在过去连续12个月中，一直在NB省居住，并为NB雇主全职工作，职业类别属于TEER 0/1/2/3类；
    • 英语或法语听说读写四项达到至少CLB 7的水平；
    • 至少具备高中学历；
    • 打算并有能力在NB省长期居住；
    • 满足或可豁免联邦最低资金要求；
    • 年龄在19-55岁之间；
    • 在NB省提名EE类别评分表中至少达到67分。

    NB利益类

    • 在联邦EE池中拥有有效的个人账户；
    • 在联邦EE账户中收到了NB移民局的意向书；
    • 在过去十年中至少具备一年连续带薪工作经验，职业类别属于TEER 0/1/2/3；
    • 英语或法语听说读写四项达到至少CLB 7的水平；
    • 至少具备高中学历；
    • 打算并有能力在NB省长期居住；
    • 满足或可豁免联邦最低资金要求；
    • 年龄在19-55岁之间；
    • 在NB省提名EE类别评分表中至少达到67分。

    申请流程 - 飞出国

    1. 创建EE账号，获得联邦EE档案号及Job Seeker验证码；
    2. 满足所有申请条件，准备好完整、正确的申请材料；
    3. 在INB系统中创建账号，进入候选池等待邀请，注册后可通过My Dashboard随时查看申请状态；
    4. 收到NB省提名申请邀请（ITA);
    5. 收到NB省提名ITA后45天内，通过NB在线系统向GBN递交完整省提名申请并支付审理费；
    6. GBN通知申请人最终审理结果，一旦获得提名，申请人需在收到提名函后九月之内向IRCC递交联邦申请；
    7. PR准签，登陆加拿大，并在登陆30天之内向PETL报告登陆。

    NBPNP 技术工人类别

    飞出国：NBPNP技术工人类别移民适用于具备有益于NB经济的技能、教育及工作经验的外国申请人，申请人必须持有NB雇主提供的长期全职工作offer，有在NB省长期工作生活的打算。2025年起，NB技术工人类别分为三个子类别：NB经验类、NB留学生类以及NB优先职业类，每个子类别有各自不同的申请条件。

    目前，NB省移民局不考虑通过NB优先职业类途径提交的EOI。此外，以下NOC代码的职业或工作offer也不被考虑。

    • 会计技师与记账员 (NOC 12200)
    • 行政助理 (NOC 13110)
    • 托运及接收员 (NOC 14400)
    • 零售和批发贸易经理 (NOC 60020)
    • 餐厅和食品服务经理 (NOC 60030)
    • 零售主管 (NOC 62010)
    • 食品服务主管 (NOC 62020)
    • 厨师 (NOC 63200)
    • 烘焙师 (NOC 63202)
    • 零售销售人员和视觉营销人员 (NOC 64100)
    • 调酒师 (NOC 64301)
    • 酒店前天 (NOC 64314)
    • 其他客户代表 (NOC 64409)
    • 餐饮服务员 (NOC 65200)
    • 食品柜台服务员、厨房帮工及相关职业 (NOC 65201)
    • 鱼肉及海鲜工厂工人 (NOC 94142)
    • 食品和饮料加工工人 (NOC 95106)
    • 鱼肉及海鲜劳工 (NOC 95107)

    EOI有效期为365天，申请并不以先到先得的方式进行审理，NB省移民审查申请并采取定向邀请的方式。

    申请条件 - 飞出国

    NB经验类

    • 申请人正在为愿意支持其申请的NB省雇主全职工作，且该职位是非季节性的；
    • 申请人在雇主的支持下至少有6个月的全职工作经验；
    • 在提交EOI之前的6个月里，申请人一直在NB省居住；
    • 具备符合职位要求的学历水平；
    • 英语或法语听说读写四项至少达到CLB 4的语言水平；
    • 打算并有能力在NB省长期居住和工作；
    • 年龄至少达到19岁。

    NB留学生类

    • 申请人毕业于NB省指定学习机构（DLI），所读课程符合毕业生工作许可（PGWP）申请条件；
    • 申请人在符合条件且愿意支持其申请的NB省雇主那里全职工作，或已接受这样的职位；
    • 具备符合职位要求的学历水平；
    • 英语或法语听说读写四项至少达到CLB 4的语言水平；
    • 打算并有能力在NB省长期居住和工作；
    • 年龄至少达到19岁。

    NB优先职业类

    • 申请人已接受符合条件且愿意支持其申请的NB省雇主提供的全职非季节性工作offer；
    • 该工作offer是由NB省政府主导的招聘会直接促成的；
    • 该职位的NOC代码必须是相应指南中指定的（见附表）；
    • 申请人至少有一年相关工作经验；
    • 具备符合职位要求的学历水平；
    • 英语或法语听说读写四项至少达到CLB 4的语言水平；
    • 打算并有能力在NB省长期居住和工作；
    • 年龄至少达到19岁。

    NBPNP 法语移民类别

    飞出国：NB省法语移民类别即New Brunswick Strategic Initiative stream，该类别针对具备技能、学历和工作经验，且能够为NB省经济做出贡献的法语技术工人，申请人需要有在NB省长期工作和生活的打算。

    2025年，该类别不接受新的申请。

    申请条件 - 飞出国

    • 申请人的年龄至少已满19岁；
    • 法语听说读写四项至少达到CLB 5的语言水平；
    • 具备高中以上学历，并通过加拿大ECA学历认证；
    • 递交申请前近十年需至少具备累积一年的全职或兼职工作经验（NB省毕业生无需工作经验）
    • 满足NB省法语移民项目评分65分；
    • 打算在NB省长期居住，提交定居计划以证明；
    • 具备足够的资金证明，如申请人当前居住在NB并/或持有工作offer，可豁免资金要求；
    • 通过以下三种方式之一，与NB省建立联系：
      • 对NB省进行探索性访问。增加说明，这种联系方式只适用于加拿大境外的申请人，如果申请人是在加拿大其他省份居住的临时居民，不适合这一方式。或；
      • 具备NB省雇主提供的工作或真实工作offer。或；
      • 属于以下NB省优先事项之一的情况：
        • 申请人在过去6个月内完成了蒙克顿大学或新不伦瑞克社区学院（CCNB）的课程；
        • 申请人已经在NB省居住了12个月，并且在魁北克以外的同一家加拿大公司远程工作了12个月；
        • 申请人收到了NB省移民官员的意向书。

    注：如果申请人是NB省的毕业生，但没有工作或工作offer，需要联系当地的Working NB办公室，了解该省的就业机会。

    NB省法语移民项目评分标准 - 飞出国

    NBPNP 关键工人试点项目

    飞出国：NBPNP关键工人试点项目（New Brunswick Critical Worker Pilot，NBCWP）于2022年年底开始运营，试点项目为期5年。同其他雇主类移民项目的初衷一致，该项目也旨在解决NB省严重的工人短缺问题。NB关键工人试点项目是一个雇主驱动的移民项目，基于雇主对技术工人的有针对性的招聘。 该计划不接受感兴趣的候选人的直接申请。

    NB移民局挑选了近3年在省提名计划(NBPNP) 中有良好信用记录以及完善的新移民安置计划的6家雇主参与该项目，它们是：

    • Cooke Aquaculture
    • J.D. Irving Ltd.
    • Groupe Savoie
    • Groupe Westco
    • Imperial Manufacturing Group
    • McCain Foods, Ltd.

    申请条件 - 飞出国

    • 年龄在19-55岁之间；
    • 英语或法语至少达到CLB 4水平；
    • 高中及以上学历，加拿大以外学历需通过ECA学历认证；
    • 过去5年中至少1年提名职业相关工作经验（从事NOC TEER 4或5类别职业的国际留学生，不可以申请该类别）；
    • 持有指定的NB雇主提供的有效工作offer，薪资水平符合NB同行业标准，也要和雇主公司内部的工资结构标准一致；
    • 如果申请人是做远程工作，则要求目前居住在NB并且在提交申请前的12个月内一直居住在NB，且持有效的工作授权为符合要求的雇主在工作；
    • 如果申请人从事的是受监管的职业，则必须获得证书或执照；
    • 所有申请都必须由雇主及申请人共同签署NBPNP-004表，以证明NB雇主的支持。

    注：如果在递交省提名申请之时，申请人不能提供合格的语言成绩、学历文凭、对等学历认证报告或合格的工作经验证明，则需要雇主提供一个签字的证明信并作为申请的一部分一起递交。
