加拿大联邦农村与法语社区移民试点项目

加拿大联邦农村与法语社区移民试点项目（RCIP & FCIP）是希望在加拿大的农村和法语社区工作和生活的技术工人获得永久居留的途径，参与社区包括：

农村参与社区 法语参与社区
Pictou County, NS Acadian Peninsula, NB
North Bay, ON Sudbury, ON
Sudbury, ON Timmins, ON
Timmins, ON Superior East Region, ON
Sault Ste. Marie, ON St. Pierre Jolys, MB
Thunder Bay, ON Kelowna, BC
Steinbach, MB
Altona/Rhineland, MB
Brandon, MB
Moose Jaw, SK
Claresholm, AB
West Kootenay, BC
North Okanagan Shuswap, BC
Peace Liard, BC

申请条件

  1. 农村社区移民试点项目

  2. 持有社区指定雇主提供的有效工作offer（每个社区会有不同的指定雇主及要求）；

  3. 在过去 3 年中，至少有 1 年（1560小时）相关工作经验；
    • TEER 0/1类工作offer需具备TEER 0/1/2/3类工作经验；
    • TEER 2类工作offer需具备TEER 1/2/3/4类工作经验；
    • TEER 3/4类工作offer需具备TEER 2/3/4类工作经验；
    • TEER 5类工作offer需具备相同五位数NOC代码的工作经验；
    • NOC 33102（TEER 3）护士护理和NOC 44101(TEER 4)的工作offer可接受NOC 31301（TEER 1）注册护士和注册精神科护士的工作经验；
  4. 毕业于社区公立高等教育机构并满足以下条件的国际学生，无需满足工作经验要求：
    • 通过2年或更长时间的全日制学习获得合格文凭，该文凭是在递交永久居留申请前18个月内获得的，过去的24个月中，至少有16个月是在社区中学习的；或
    • 通过2年或更短时间的全日制学习获得硕士或以上学位，该学位是在递交永久居留申请前18个月内获得的，学习期间一直在社区居住；
  5. 满足不同职业的语言要求，英语或法语达到以下水平：
    • TEER 0或1类职业：CLB 6
    • TEER 2或3类职业：CLB 5
    • TEER 4或5类职业：CLB 4
  6. 至少具备高中以上学历，加拿大境外学历需提供ECA学历认证；

  7. 提供足够的资金证明： | 家庭人数 | 所需资金（单位：加币） | | ------ | ------ | | 1 | $7,963 | | 2 | $9,692 | | 3 | $12,069 | | 4 | $15,056 | | 5 | $17,145 | | 6 | $19,015 | | 7 | $20,884 | | 7人以上每增加1人 | 增加$1,869 |

  8. 法语社区移民试点项目

  9. 持有社区指定雇主提供的有效工作offer（每个社区会有不同的指定雇主及要求）；

  10. 在过去 3 年中，至少有 1 年（1560小时）相关工作经验；
    • TEER 0/1类工作offer需具备TEER 0/1/2/3类工作经验；
    • TEER 2类工作offer需具备TEER 1/2/3/4类工作经验；
    • TEER 3/4类工作offer需具备TEER 2/3/4类工作经验；
    • TEER 5类工作offer需具备相同五位数NOC代码的工作经验；
    • NOC 33102（TEER 3）护士护理和NOC 44101(TEER 4)的工作offer可接受NOC 31301（TEER 1）注册护士和注册精神科护士的工作经验；
  11. 毕业于社区公立高等教育机构并满足以下条件的国际学生，无需满足工作经验要求：
    • 通过2年或更长时间的全日制学习获得合格文凭，该文凭是在递交永久居留申请前18个月内获得的，过去的24个月中，至少有16个月是在社区中学习的；或
    • 通过2年或更短时间的全日制学习获得硕士或以上学位，该学位是在递交永久居留申请前18个月内获得的，学习期间一直在社区居住；
  12. 法语听说读写四项均达到CLB 5的语言水平；
  13. 至少具备高中以上学历，加拿大境外学历需提供ECA学历认证；
  14. 提供足够的资金证明： | 家庭人数 | 所需资金（单位：加币） | | ------ | ------ | | 1 | $7,963 | | 2 | $9,692 | | 3 | $12,069 | | 4 | $15,056 | | 5 | $17,145 | | 6 | $19,015 | | 7 | $20,884 | | 7人以上每增加1人 | 增加$1,869 |

申请流程

  1. 获得指定社区雇主提供的工作offer；
  2. 雇主将社区推荐申请直接发送到社区进行审核；
  3. 获得社区推荐，提交永久居留申请；
  4. PR准签。
